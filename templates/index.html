How this works (pipeline)
1. Preprocess — 3 papers → sections → ~130-word chunks ({{ n_chunks }} chunks total), each tagged with paper + section metadata (build_corpus.py, run once, offline).
2. Retrieve — your question and every chunk are converted to TF-IDF vectors by scikit-learn on the server (retriever.py); the 8 chunks with highest cosine similarity to your question are selected.
3. Generate — the question plus the 8 retrieved excerpts are sent to Claude (claude-sonnet-4-6) from the server (generator.py), instructed to answer only from those excerpts and to cite them as [1]..[8].
4. Attribute — citation markers in the answer are turned into links to the source cards below (app.py's linkify_citations), which show the paper, section, similarity score, and full excerpt text. No JavaScript is used anywhere in this page — the citation links work via plain HTML anchors (#source-n) and the :target CSS pseudo-class.
